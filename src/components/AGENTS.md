- Evolução Produtos (Home shortcut and Sinistralidade submenu, separate permissions, one screen) reads lives from the carteira_evolucao_produtos cache and financial views from evolucao_produtos_financeiro (view_eard_mensal; Fácil 50 per matrícula via beneficiarios); its Cidade (UF) grid (Praça grouping and the flat XLSX data model built by modeloDadosCidades) reads JSON-array RPCs from supabase/sql/evolucao_produtos_cidades.sql (plan municipality by IBGE code, lives cache refreshed alongside the main cache), reconciling to the same totals; its month × Praça grid dialog (icon beside Gerar XLSX) transposes that same grade via tested gradePracasPorMes, never querying again; its Gerar PDF (src/lib/evolucaoPracasPdf.ts, letterhead via the shared PdfPreview) draws those same rows, with tested resumoPracas cards and ajusteGrade sizing so the grid fits one page when possible. Its "Incluir ANS" option (Vidas with Tipo/Produto Todos only, tested podeIncluirAns, except when opened from Movimentação, where it is always available and still shows the operator total) adds the Bench Vidas Mensal Bensaúde Plano de Saúde total per month via tested src/lib/evolucaoPracasAns.ts over the same monthly assets and agregarMensal as the Bench Vidas screen, so both screens always show the same ANS figures. Period, grouping, filters, subtotals, Total column (hidden in the Cidade grid when the period has no sum, e.g. Vidas) and ratio-of-sums formulas for both grids live in tested src/lib/evolucaoProdutos.ts so the screen never computes amounts and Evolução Mensal/Sinistralidade stay untouched.
- Carteira › Movimentação's "Cidades" icon (shown only with Evolução Produtos access) opens the same EvolucaoProdutos screen in somenteCidades mode (Vidas only, no top bar) with periodoFixo taken from the typed De/Até, inside a dialog, so the Cidade (UF) view is never duplicated and never triggers Movimentação queries.
