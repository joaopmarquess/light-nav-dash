- Evolução Produtos (Home shortcut and Sinistralidade submenu, separate permissions, one screen) reads lives from the carteira_evolucao_produtos cache and financial views from evolucao_produtos_financeiro (view_eard_mensal; Fácil 50 per matrícula via beneficiarios), both in supabase/sql; 12-month period from the chosen end month, grouping, product-filtered subtotals, period Total column, indicator formulas, subtotals and totals (ratios as ratio of sums) live in tested src/lib/evolucaoProdutos.ts so every view shares one grid without touching Evolução Mensal or Sinistralidade.

- Modelo de Atuação › Comercial (also opened from Estudo › Comercial, one shared component) derives each table from the Referência × per-table index in tested src/lib/uberabaTabelasComerciais.ts (Enfermaria rounded, Apartamento = TRUNC(Enf × 1.25; 2)), indices stored in this browser, so the screen never holds hard-coded prices.
- Modelo de Atuação fronts reuse the Guias visual system: Rede Assistencial renders through the Guias component with content derived from the credentialing helper, Comercial through its own component with only the user-supplied content, both typed in tested src/lib/uberabaFrentes.ts so Guias itself never changes.
